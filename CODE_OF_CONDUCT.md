# Code of Conduct

This project is for people building safer AI-assisted infrastructure operations.

## Our Standard

Contributors are expected to:

- Be respectful and constructive.
- Assume good intent while still being precise about risk.
- Keep feedback focused on the work, evidence, and safety impact.
- Avoid publishing private infrastructure details, credentials, personal data, or organization-specific secrets.
- Help make Proxmox, homelab, and production-ops knowledge more reusable for everyone.

Unacceptable behavior includes harassment, intimidation, discriminatory language, personal attacks, doxxing, and publishing secrets or private infrastructure details without consent.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or block contributors whose behavior harms the project or its users.

Report concerns privately to the repository maintainer.
